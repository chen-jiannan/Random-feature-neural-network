# Contributing

Thank you for your interest in this repository.

## Scope

This repository is primarily intended to archive the code and manuscript associated with the published research results. Minor improvements, reproducibility fixes, and documentation clarifications are welcome.

## Before contributing

Please open an issue first if you plan to:

- refactor notebook structure
- change numerical defaults
- alter figure-generation logic
- add new benchmark cases

## Recommended contribution style

- keep scientific behavior unchanged unless clearly documented
- avoid breaking existing notebook execution order
- document any new dependencies
- provide short notes on reproducibility impact

## Pull requests

Please include:

1. a clear summary of the change
2. the reason for the change
3. any effect on results, figures, or runtime
